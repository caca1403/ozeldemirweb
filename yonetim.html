Nasıl yayınlanır?
  1. İlanı ekle ve İlanı kaydet'e bas.
  2. Üstteki Siteye gönder'e bas.
  3. İlk seferde canlı site için GitHub bağlantısını bir kez kur. Sonrasında tek tuşla yayınlanır.
  4. 1-2 dakika içinde sitede görünür.

GitHub istemiyorsan “Bu bilgisayar” seçeneğiyle site klasörüne doğrudan yazabilirsin. Dosya indirme seçeneği de duruyor.

GitHub’da Settings → Developer settings → Personal access tokens → Generate new token yolunu izleyip repo yetkisiyle bir anahtar oluştur, kopyala, buraya yapıştır. Anahtar yalnızca bu tarayıcıda saklanır. Doğrudan anahtar sayfası
